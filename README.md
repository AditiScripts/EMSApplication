# Expense Manager Software Application
An interactive, menu‐driven Java application for tracking and managing personal and business expenses. Built with Java object‐oriented design and MySQL for robust data storage, this tool replaces error-prone Excel sheets with a secure, scalable, and maintainable solution.

## Features

- **CRUD Operations**  
  - Add, edit, or delete expense entries with guided prompts.  
- **Multiple Categories**  
  - Track subscriptions, utilities (gas, electricity), internet bills, and more.  
- **Tabular Output**  
  - Display expense lists and filtered results in clean, console-based tables.  
- **Interactive Menu**  
  - Navigate with numbered options:  
    1. Create new expense  
    2. Edit existing expense  
    3. Delete expense  
    4. View all expenses  
    5. Filter by category or date  
    6. Exit  
- **Java OOP Design**  
  - Modular classes (models, DAOs, services, UI) for easy maintenance and extension.  
- **MySQL Backend**  
  - Persistent, ACID-compliant storage  
  - Secure access via JDBC  
  - Cross-platform compatibility  
  - Built-in backup and recovery features
