# Expense Manager Software Application
An interactive, menu‐driven Java application for tracking and managing personal and business expenses. Built with Java object‐oriented design and MySQL for robust data storage, this tool replaces error-prone Excel sheets with a secure, scalable, and maintainable solution.

## Features

- **Add / Edit / Delete Expenses**  
  Easily create, update, or remove expense records.

- **Multiple Expense Categories**  
  Supports subscriptions, utilities (gas, electricity), internet bills, and more.

- **Tabular Display**  
  View your expense data in neatly formatted tables on demand.

- **Interactive Menu**  
  Guided, error‐resistant prompts let you choose exactly what you need:
  1. Create new expense  
  2. Edit existing expense  
  3. Delete expense  
  4. View all expenses (tabular)  
  5. Filter by category or date  
  6. Exit

- **Java OOP Design**  
  - Reusable classes and methods  
  - Clear separation of concerns  
  - Easy to extend and maintain  

- **MySQL Backend**  
  - Persistent storage of multiple related tables  
  - ACID compliance for data integrity and consistency  
  - Built-in backup and recovery  
  - Cross‐platform compatibility  
  - Secure access via user roles  
  - JDBC connectivity for seamless SQL operations

## Prerequisites

- Java Development Kit (JDK) 11 or later  
- MySQL Server 5.7 or later  
- JDBC Driver for MySQL (Connector/J)  
- (Optional) Maven or Gradle for build automation
